# Images folder

The current prototype uses remote Unsplash image URLs so the project ZIP stays small.

For a fully self-contained version, download only images you have permission to use, place them in this folder, and update the URLs in `assets/css/styles.css` and `assets/js/tours.js` to local paths such as `assets/images/quiet-khlongs.jpg`.

Use authentic, licensed photos for any real business launch. Do not use another company's copyrighted images without permission.
